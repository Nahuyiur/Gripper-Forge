# 夹爪设计器

这是一个以 `zhuti-2-0813.stl` 的三孔安装区和 `底座.stl` 为默认接口的本地参数化夹爪设计网页。原始夹爪与 Fin-Ray 使用两套独立的参数和几何生成器，包含浏览器即时三维预览、实体检查和可打印 STL 导出。

## 已实现的能力

- 两个大类：原始夹爪、Fin-Ray 默认；防滑纹、圆物托槽和指甲薄片属于 Fin-Ray 小类
- 两个大类分别保存自己的参数状态，切换大类不会互相覆盖或改写
- 原始夹爪支持全实心、仅尖端伪 Fin-Ray、仅后段伪 Fin-Ray、尖端＋后段四种内部结构组合
- 原始夹爪尖端与后段分界可调，两区的中空程度、斜条数量和斜条厚度完全独立
- 原始夹爪保留源 STL 风格，可独立调整有效长度、指尖厚度和指尖侧偏
- 左右对称或分别编辑手指 A、手指 B
- 长度、指尖厚度、内扣、外壁、内部肋条、托槽、防滑纹和指甲薄片参数
- 14 个参数逐项有效；托槽、纹路形状和指甲厚度等依赖型控件会自动启用配套几何
- 拖动旋转、滚轮缩放、双击复位和四个标准视角
- 滑块与精确数值输入
- 拖动参数时连续重建真实主体／底座 STL；过时的中间请求会被跳过，最终状态始终与导出模型一致
- 实时替换 STL 时保留当前旋转、缩放与观察中心，便于直接比较参数变化
- 防抖实体检查：封闭性、三角面方向、退化面、体积和安装区域漂移
- 双指接触面保持 28 毫米预览净距，避免互相穿插
- 所有接触特征直接写入二维轮廓，不再以外挂方块近似
- 配套 `底座.stl` 是连接 Robotiq 夹爪的转接座，不是装饰或独立参考件
- 每次打开网页都以当前 `zhuti-2-0813.stl + 底座.stl` 作为默认成对模板，不自动沿用上一次临时导入
- 支持分别选择主体 STL 和底座 STL，并把两者作为一对导入、预览、检查和继续参数化编辑
- 三维预览支持“仅主体”“仅底座”“主体＋底座”三种显示模式
- 主体与底座通过三颗螺丝连接，接口一致性会参与每次几何检查
- 异步生成单只或左右两只 STL，并可下载 ZIP 文件包
- 未经修改的原始 STL 随时可下载
- 桌面三栏布局和移动端粘性预览

## 核心几何约束

原始模型的 `y <= 55 mm` 区域被视为主体与 Robotiq 转接底座的安装接口。主体与底座通过三颗螺丝连接，这三颗螺丝的相对位置属于成对接口约束，不能只修改一侧。底座平面上的孔用于连接 Robotiq，是第二层安装约束。

当前所有可调参数都被限制在接口区域之外。Fin-Ray 生成器截取并锁定三孔安装实体，再以它为根部生成 Fin-Ray 活动区；原始夹爪生成器则直接变形源 STL 的安装区以上顶点，并从真实中剖面轮廓内切出侧面贯穿空腔。两套生成器都要求接口偏差为 `0.000000 mm`。如果未来新增参数确实需要改变三颗螺丝的相对位置，则必须同步生成匹配的新底座；否则检查必须失败，禁止导出。

导入模型时会检查主体和底座是否为封闭实体、是否各识别到三个安装孔、三条孔轴是否共轴，以及底座平面孔型和外形是否仍符合当前 Robotiq 基准。只有接口与坐标方向都通过的模型对才能继续使用当前参数化编辑和导出；未通过的模型仍可组合预览以便排查。

刷新后的原始夹爪逐顶点、逐三角面显示源主体，同时显示原始底座。修改原始夹爪时只调用原始夹爪生成器：两区中空都为零时得到可变形的全实心源夹爪；开启任一区域后，只在该区域切出侧面贯穿空腔并保留斜条。只有主动选择 Fin-Ray 大类或其小类时，才调用 Fin-Ray 轮廓、斜肋和空腔生成器。最终下载文件以后端的封闭性、方向、退化面、单一实体和孔位检查为准。

## 参考边界

设计方法参考了 Finger Mod 公共页面、公开前端模块和参数接口所呈现的行为，但没有直接复制未声明许可证的源码。原站面向 SO-101，只生成手指并使用 XLeRobot 的固定安装件；本项目独立实现为当前 Robotiq 三孔主体／底座接口，不能把两者的安装尺寸混用。

## 本地运行

需要 Node.js 20 或更高版本，以及 Python 3.12。首次使用时安装依赖：

```bash
npm install
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

同时启动网页和本地几何服务：

```bash
npm run dev:all
```

网页地址为 `http://localhost:3000/`。几何服务地址为 `http://127.0.0.1:8787/`。

## 仓库结构

```text
app/       网页界面、Three.js 预览与参数状态
backend/   STL 几何生成、检查、导入和导出接口
public/    默认主体与 Robotiq 转接底座 STL
tests/     后端几何、参数矩阵和前端契约测试
db/        可选的持久化数据结构
worker/    部署运行入口
```

## 验收

```bash
npm test
```

测试会完成网页生产构建、全部模板和全部接触特征的几何检查、三螺丝孔位锁定、主体／底座接口检查、三种显示模式、生成/下载回环和中文前端能力契约检查。压缩文件包会同时包含当前主体和对应的 Robotiq 转接底座。

参数矩阵会分别检查 Fin-Ray 的 14 个控件和原始夹爪的 11 个独立控件，证明每个控件都会改变对应预览与后端 STL。两套生成器分别覆盖 160 组固定随机组合，并检查全低、全高、交错极值、四种原始内部结构和左右非对称结构。所有组合都必须满足有限坐标、封闭实体、面方向一致、零退化面、单一实体和三孔零漂移。

## 物理验证边界

软件检查通过代表网格和安装接口的数字几何约束通过，不等同于已经完成实物装配和抓取验证。首次打印后仍应测量孔距、试装、低速闭合并测试材料疲劳。

## 版本约定

- `main` 只保存已经通过完整自动化测试的稳定版本。
- 稳定版本使用 `v主版本.次版本.修订版本` 标签，例如初始稳定基线 `v0.1.0`。
- 每次调整几何逻辑时，必须同时验证浏览器预览、最终导出 STL、主体／底座接口以及固定 Robotiq 安装特征。
