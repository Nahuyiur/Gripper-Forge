# 新增基本构型

Gripper Forge 把“基本构型”视为可编辑模型的最上层单位。当前已注册原始夹爪、Fin-Ray、弧面包覆和精密尖指四个构型族；以后收到新的 STL，不需要继续向现有构型追加无关参数。

## 一个构型族包含什么

只有 STL 还不足以可靠参数化。STL 只保存三角面，不知道哪里是安装区、孔、指尖或应当保持不动的边界。因此，一个可编辑构型族必须同时提供：

| 内容 | 作用 |
|---|---|
| 主体 STL 种子 | 定义该构型的默认外形；纯程序生成的构型可以没有 |
| 配套底座 STL | 定义与机器人连接的默认几何 |
| 参数 schema | 参数名称、单位、范围、步长与 UI 分组 |
| 几何生成器 | 说明每个参数如何真实改变网格 |
| 接口适配器 | 将共享三孔参数同时应用到主体和底座 |
| 接口默认值 | 保持 Robotiq 三孔约束，并选择适合该构型根部轮廓的默认孔距 |
| 验证规则 | 封闭性、单实体、孔位、壁厚和固定特征等不变量 |
| 预设 | 该构型内部的常用参数组合，不另起一个生成器 |

## 推荐目录

```text
public/families/<family_id>/
├── body.stl
└── base.stl

backend/
├── families.py          构型族注册契约
├── geometry_families.py 独立程序构型生成器
├── schema.py            注册构型、参数和预设
└── model.py             连接对应几何生成器
```

`family_id` 是设计文件和 API 使用的稳定标识，不应使用会频繁修改的中文显示名称。

## 注册步骤

1. 将经过确认的主体和底座放入独立的构型资产目录。
2. 为该构型定义参数、分组和默认值。
3. 实现专属几何生成器；不能用 Three.js 缩放冒充 STL 修改。
4. 在 `FAMILY_REGISTRY` 注册种子、生成器、默认预设和版本。
5. 为每个参数的低值、高值、组合值和默认 no-op 增加测试。
6. 检查共享接口、实时预览、最终 STL 和 ZIP 使用同一次设计求值。

## 两种导入语义

- **临时导入**：用户在网页中选择一对 STL，只做匹配检查和预览；因为没有特征语义，不自动获得参数。
- **注册构型**：STL 经过特征定义、生成器实现和测试后进入构型库，之后每次打开都可以选择并编辑。

未来如果增加自动特征识别，它也只负责生成“待审核的构型草稿”；在孔位、固定面和变形规则确认前，不直接提升为可导出的正式构型。
